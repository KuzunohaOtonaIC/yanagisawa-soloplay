# 柳澤流ソロプレイツール

MTG の一人回し用 Web アプリです。ビルドもサーバーも不要です。

**公開版: https://kuzunohaotonaic.github.io/yanagisawa-soloplay/**

## 使い方

1. 公開版を開く（手元で使う場合は `index.html` をブラウザで開くか、`npm run serve` → http://localhost:8000 ）
2. 「txtファイルから読み込む」でデッキのtxtを選ぶ（ファイル名がデッキ名になります）か、
   デッキ名を入れて MTGO 形式のリストを貼り付けて「読み込んで保存」
3. デッキを選んで「開始」（組み込みデッキ3つは最初から入っています）
4. 一人回し画面の操作
   - 初手で「マリガン」（ロンドン・マリガン）。マリガンしないならそのままプレイ開始
   - 手札のカードをクリック → 場に出す
   - 場のカードをクリック → タップ／アンタップ。カードの下のボタンで墓地・手札・追放へ
   - 墓地・追放のカードはボタンで手札・場へ戻せる
   - 「上へ」「下へ」ボタン → ライブラリーの一番上／一番下に置く（手札・場・墓地・追放・ライブラリーの中から）
   - 手札の一番右の「ドロー」ボタン（または D キー）→ 1枚引く
   - ライブラリーのカードをクリック → 手札に加えてライブラリーをシャッフル
   - 「次のターンへ」→ 場のカードをアンタップし、ターン数を進めて1枚引く
   - 「元に戻す」（または Z キー / Ctrl+Z）→ 直前の操作を取り消す

カード種類と日本語名は Scryfall から取得します（インターネット接続が必要。一度取得したカードはブラウザに保存され、次からは問い合わせません）。

日本語名や画像が出ないときは、デッキ一覧の下の「Scryfall 接続チェック」を押すと、どこで止まっているかと考えられる原因が表示されます。

デッキはブラウザの localStorage に保存されます（`file://` で開いた場合と `http://localhost` で開いた場合では保存先が別になります）。
